# 文字界面与导航

1.2.1 沿用方案一「整列半隐」，子菜单和应用网格移除独立标题，仅保留顶部面包屑。列表按实际内容高度整体垂直居中；超出安全高度时居中的是滚动视口。菜单与首页常用列表共用左边距，首页常用列表以屏幕高度 43% 为起点上限，按五行空间向上适配。

仅保留最近一级父菜单的半截文字，透明度为 23%；更早的上级退出画面。父级位置保持不变。

`ParentMenuView` 独立绘制父级残影，每行将前半截移出屏幕，靠近子级的一侧进一步渐隐。残影的可见宽度受首页左边距限制，保留父子之间的间隔，长菜单名也不会覆盖子级。标题与返回提示仍在安全区域内。

## 焦点

`TextActionView` 在固定的点击与焦点矩形内绘制放大的文字。选中项在 150 毫秒内放大到 1.2 倍、变为纯白；其他文字保持灰色。单元格预留右侧空间，焦点变化不触发行高或列宽变化。长名称省略或在应用网格中最多显示两行。

父级仅用作上下文：不能接收遥控器焦点、点击或辅助功能遍历。父级原来的选中项保持强调，再随整列渐隐。应用网格成为父级时，以所选项附近的文字条目显示残影。原页面保留原有尺寸及滚动位置，不因残影裁切而重新排版。

## 导航

- 返回键逐级返回，恢复父级选中项和滚动位置。
- 文字列表按左返回；网格按左移到相邻项，最左列按左返回。
- 网格的上下左右不会跳入占位单元格或渐隐父级。
- 1.2.5 起文字菜单上下首尾循环；应用及常用编辑网格沿同一列循环，末行不满时使用该列实际存在的首末项。跨屏跳转直接显示目标项。
- 首页常用首项按上进入底部“全部应用”，末项按下也进入“全部应用”；底部操作项按上回到末个常用，按下回到首个常用。底部左右选择不变；空名单的“添加常用应用”占据同一位置。
- Home 入口关闭所有菜单，恢复首页焦点；既有 Home 兼容服务继续独立处理厂商差异。
- 菜单键进入设置；从更深层按菜单键会回到已有设置页，不重复叠加设置。
- 许可与使用说明从开头进入，使用上下键滚动，返回键退出。

每个菜单保留自己的选中项和滚动位置。常用应用仍以包名为标识，字号、边距、壁纸与常用名单沿用已有本机偏好。旧的 Dock 布局偏好不会删除，当前界面统一显示文字列表。

## 检查

```sh
python3 scripts/navigation_check.py --adb /path/to/adb --serial <电视IP>:5555 --out /tmp/skyhome-navigation
```

检查菜单视口垂直居中、与首页左边距一致且无重复标题、背景菜单、深层返回、编辑网格、应用网格边界、长按及 Home 入口。此脚本会操作前台界面并保存设备截图，不改保存的偏好。不要同时使用实体遥控器。UIAutomator 可能暂时抑制其他辅助功能服务，因此实体 Home 与跨重启测试需单独执行。

系统信号源、系统设置及投屏应用的界面仍由各自应用绘制。其他分辨率、字体缩放与创维固件应分别验证，不能以本机截图代替。


## 大字方案回调（2026-10-29）

根据电视现场反馈回调字号，沿用已有「标准 / 大 / 特大」偏好，默认仍为中间档。

| 位置 | 标准 | 大（默认） | 特大 |
| --- | --- | --- | --- |
| 首页应用名 | 30sp | 34sp | 38sp |
| 菜单选项 | 26sp | 28sp | 32sp |
| 应用网格 | 22sp | 24sp | 28sp |
| 底部操作 | 20sp | 22sp | 24sp |

「常用应用」标题从 16sp 增大到 20sp。字号与最小行高统一由 `Typography` 管理。首页文字区保持 460dp（不超过左右安全边距），按五行空间和底部操作的实际高度计算起点与滚动视口。首页最小行高为 58 / 62 / 68dp，菜单为 62 / 66 / 74dp，网格为 94 / 100 / 112dp。系统字体缩放需要更多空间时，行高按字体度量进一步增加，为 1.2 倍焦点文字留白。

全部应用与常用编辑网格恢复四列，保留最多两行名称、省略、长按管理、同列上下循环及最左列按左返回。父级残影跟随对应页面的字号与行距。时钟沿用 58sp。

安装后需检查三档字号、长中文应用名、九项常用滚动、四列末行不满、深层返回与系统字体缩放。


## 五个常用与无箭头细轨道（2026-10-29）

常用上限为五个，读取旧名单时按原顺序取前五个有效应用，不因读取或升级重写原始名单；用户显式编辑保存时按五个上限写入。编辑计数、添加限制与满额提示共用 `MAX_FAVORITES`。

首页为五个完整行位预留空间，必要时整体上移，与品牌和底部操作保持间隔；不足五项不补条目。极小屏幕或较大系统字体无法容纳五行时保留字号并减少可见行数。

首页、文字菜单、应用/常用编辑网格和正文页统一使用 `RailScrollView`。只有内容超出视口时显示右侧细轨道和滑块；滑块按实际滚动范围与偏移定位，到顶/到底仍保留轨道，全部可见时隐藏。轨道无箭头、不接收焦点，右侧预留 20dp 避免覆盖文字。上下循环和返回规则保持原样。
