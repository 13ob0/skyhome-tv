## 检查中修复

- 为时钟设置显式自适应宽度与单行，消除分钟末位被裁切。
- 触摸建立焦点后继续支持方向键；常用编辑后保留当前应用焦点。
- 首页重建期间不覆盖焦点记录，离开应用保存上次选中项。
- 支持部分遥控器以重复确认键事件表示长按，并消费对应松开事件，防止误启动。
- 当贝投屏启动时出现其自身强制更新页，投屏快捷入口改为优先使用创维内置爱投屏。

## 边界

上述方向键和长按检查使用 ADB 注入的遥控事件，不能替代所有实体遥控器和固件组合。照片定时轮播、九项极限布局、所有应用逐项启动、手机实际投屏、HDMI 音视频、连续待机与长期内存峰值未完成覆盖验证。Gradle 构建路径提供工程配置，本次实际使用直接 SDK 构建脚本，没有在 Android Studio 中另行构建。

`scripts/device_check.py` 可复现主要入口检查。完整原始截图和临时运行日志只留在本机临时目录，不纳入公开源码包。

## 常用列表滚动修复

按各行已经取整的像素高度与实际间距计算视口，取消末项尾间距，消除 density 240 下的像素舍入溢出；滚动容器不再作为遥控器焦点，关闭回弹与边缘渐隐。列表超过视口时仍保留真实内容滚动。

## 信号源入口修复

原入口 `coocaa.intent.action.SWITCH_SOURCE` 实际为播控牌照调试页面，初次仅核对 Activity 启动而误判。现改用 `coocaa.intent.action.SOURCE_DIALOG`（限定创维原桌面包）。更新后的应用已从首页点击验证：显示 HDMI1、HDMI2、电视直播与视频；方向键选择 HDMI1 并确认后进入创维 TV，屏幕显示 HDMI1 和“无信号”。这验证了菜单与 HDMI1 切换链路，未验证外接设备音视频。测试后返回山岚桌面。

## Home 兼容服务（2026-10-24）

确认固件会还原厂商 Home 属性，不能只依靠 setprop。用户已明确允许启用辅助功能 Home 服务。服务已启用并绑定，系统能力位为 8，不含获取窗口内容的能力；只订阅两个创维系统桌面包的窗口状态，处理三个已知桌面类名，并在手动打开原桌面时短暂放行初始化。Home 从系统设置、HDMI 返回山岚通过；原桌面本身的实体 Home 行为及服务跨重启仍待确认，未标为通过。服务配置支持保留其他辅助功能项的启用/关闭脚本。

UIAutomator 可能临时抑制其他辅助功能服务，因此 Home 实机检查应使用原生遥控事件、Activity 状态和截图，不用 UIAutomator 同时操作。
